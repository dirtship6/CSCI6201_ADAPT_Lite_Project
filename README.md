# CSCI6201_ADAPT_Lite_Project
Final Project for GWU CSCI 6201 - Fall 2026

Team: 
Cole VonOhlen

Description: 
Create a Python codebase that will leverage NASA's Advanced Diagnostics and Prognostics Testbed (ADAPT) challenge dataset. This testbed data will be used to ingest, process, and create a simple machine-learning model that can identify a healthy spacecraft power system from a faulty one. 

Dataset: 
DXC'09 Industrial Track, Tier 1 (ADAPT-Lite)
Sample (training) data: https://catalog.data.gov/dataset/dxc09-industrial-track-sample-data
Competition (test) data: https://catalog.data.gov/dataset/dxc09-industrial-track-competition-data

Research Target: 
Classification model that will identify healthy vs faulty spacecraft power systems.

Gained a better understanding of how to structure multiple functions and how to organize them properly. Good foundation to proceed with the remainder of the build out.
